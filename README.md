# Bags and Gloves — Marketing Team Hub

- `index.html` — public **request page** (anyone can send a request; it reads no internal data).
- `team.html` — internal **team dashboard**; locked until the server verifies a Google sign-in from an allowed marketing account.
- `apps-script/` — the Google Apps Script backend. See `apps-script/SETUP.md`.

Private settings (`Config.gs`, `Snapshot.gs`) are intentionally not in this repository.
